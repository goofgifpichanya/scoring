# 🏆 ระบบลงคะแนนประเมินผลการอบรม (Scoring System)

ระบบประเมินผลงานสำหรับ 2 รุ่นการอบรม (รวม 31 ทีม) พร้อมระบบตรวจสอบคะแนนเรียลไทม์ และ Admin Dashboard สรุปผลคะแนน

## 📌 คุณสมบัติเด่น (Features)

- **รองรับ 2 รุ่นการอบรม**:
  - **รุ่นที่ 1 (16 ทีม)**: บส., สป., ลอ., ตส., สง., อส., พล., จท., ตท., สบ., ธญ., นร., บน1., บน2., พธ., สส.
  - **รุ่นที่ 2 (15 ทีม)**: กค., บช., บอ., งฝ., บง., ทน., อก., สว., กก., รส., ผท., งส., ธต., LPS, ธง.
- **เกณฑ์การประเมิน 6 หมวด (100 คะแนนเต็ม)**:
  - ข้อมูลและคุณภาพ (15)
  - Analysis & Insight (20)
  - Report / Dashboard (20)
  - Power BI (15)
  - Presentation (15)
  - Creativity & Practical Use (15)
- **ระบบตรวจสอบข้อผิดพลาด**: บล็อกการกรอกเกินคะแนนเต็มแต่ละหมวดแบบเรียลไทม์
- **Pre-Submit Review Modal**: หน้าทบทวนสรุปคะแนนก่อนบันทึกจริงเพื่อป้องกันการกรอกผิด
- **Admin Dashboard**: สรุปตารางอันดับ (Leaderboard), กราฟวิเคราะห์, ปุ่มสร้าง Demo Data และส่งออกรายงาน CSV/Excel

## 🛠️ การติดตั้งและใช้งาน (Getting Started)

```bash
# ติดตั้ง dependencies
npm install

# รันระบบจำลองบนเครื่อง (Development Server)
npm run dev

# Build สำหรับย้ายไปใช้งานบนเซิร์ฟเวอร์ (Production)
npm run build
```
